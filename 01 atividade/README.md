## 📌 Sobre o Projeto

Nesta atividade foi desenvolvido um projeto em **React** com o objetivo de praticar o uso de **variáveis** dentro de um componente.

A aplicação apresenta as principais informações de um produto de forma organizada e dinâmica.

---

## 🎯 Objetivo

Criar uma aplicação React capaz de armazenar e exibir os dados de um produto utilizando variáveis.

### 📦 Informações do Produto

* **Nome**
* **Descrição**
* **Marca**
* **Preço**

---

## 💻 Conceito Praticado

O principal conceito trabalhado nesta atividade foi a utilização de **variáveis em componentes React**.

As informações do produto são armazenadas em variáveis JavaScript e posteriormente utilizadas dentro do JSX para serem exibidas na tela.

### Exemplo:

```jsx
const nome = "Notebook";
const descricao = "Notebook para estudos";
const marca = "Dell";
const preco = 3500;
```

Depois, os valores podem ser apresentados utilizando JSX:

```jsx
<h2>{nome}</h2>
<p>{descricao}</p>
<p>{marca}</p>
<p>R$ {preco}</p>
```
