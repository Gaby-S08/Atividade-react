## Sobre a atividade

Esta atividade foi desenvolvida com **React** com o objetivo de praticar conceitos fundamentais da biblioteca, como **variáveis, componentes, Props e JSX**.

Durante o desenvolvimento foram criados diferentes componentes para representar informações de produtos, usuários, pessoas e carros.

---

## Conteúdos praticados

| Conceito    | Aplicação                               |
| ----------- | --------------------------------------- |
| Variáveis   | Armazenamento e exibição de informações |
| Componentes | Criação de componentes reutilizáveis    |
| Props       | Envio de informações entre componentes  |
| JSX         | Estruturação dos elementos da aplicação |
| Arrays      | Armazenamento de vários objetos         |
| `.map()`    | Exibição de listas de dados             |

---

## Atividades desenvolvidas

### 01 — Trabalhando com variáveis

Foi criado um projeto para apresentar os dados de um produto:

* Nome
* Descrição
* Marca
* Preço

### 02 — Componente `DadosUsuario.jsx`

Foi desenvolvido um componente responsável por exibir informações de um usuário:

* Nome
* Sobrenome
* E-mail
* Sexo
* Idade

### 03 — Props com `Pessoa.jsx`

Foi criado o componente `Pessoa.jsx`, utilizando **Props** para receber e exibir:

* Nome
* Idade
* Cidade
* Endereço

### 04 — JSX e componente `Carro.jsx`

Foi desenvolvido o componente `Carro.jsx`, responsável por apresentar uma lista com **5 carros**, contendo:

* Nome
* Modelo
* Marca
* Preço

## Objetivo

O principal objetivo desta atividade é desenvolver uma base de conhecimento em **React**, compreendendo como componentes são criados, como informações podem ser armazenadas em variáveis e como dados podem ser enviados através de **Props**.

## Desenvolvimento

Projeto desenvolvido para fins acadêmicos, como prática dos fundamentos do React e desenvolvimento de aplicações utilizando componentes.
